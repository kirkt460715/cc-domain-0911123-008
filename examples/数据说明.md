# 老化巡检区间

records 每行是试件的巡检摘要；时间以进入实验的统一原点后的天数表示。entry_day 是进入观察时间，left_day 是最后一次已知未失效的时间；kind 为 interval 时 right_day 是第一次已知失效时间，为 right 时 right_day 为空。temperature_c 为摄氏温度，batch 为共同材料批次。原始巡检可使用相同 schema 另登记版本，禁止将区间端点直接当精确失效日；区间须以 `input_format=interval_summary` 分析，精确失效须显式标为 kind=exact。

context 将摘要按强类型 schema 写入 Trialvault，并独立批准为本地研究发布。use_temperature_c 只表示业务拟评估的使用温度，不含寿命答案。

inspection_records 保留巡检原始行，result 为 normal 或 failed；kind=exact 是精确失效，左右端点相等。每个试件的 entry_day 独立保存，右删失由最后一次正常巡检结束。首检即 failed 的试件，其区间左界退回 entry_day，故不能把首次发现失效那天当作精确寿命；发现失效后又恢复的记录在拟合前诊断并剔除。

`python -m trialvault demo` 的寿命实验段以 inspection_records 的长表输入运行：区间 52、右删失 8（其中 ongoing 8）、延迟进入 12；另以同一原始数据核对了精确/区间/右删失/延迟进入四种似然项与 25 °C↔298.15 K、100 °C↔373.15 K 的换算。
