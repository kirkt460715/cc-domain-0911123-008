# 老化巡检区间

records 每行是试件的巡检摘要；时间以进入实验的统一原点后的天数表示。entry_day 是进入观察时间，left_day 是最后一次已知未失效的时间；kind 为 interval 时 right_day 是第一次已知失效时间，为 right 时 right_day 为空。temperature_c 为摄氏温度，batch 为共同材料批次。原始巡检可使用相同 schema 另登记版本，禁止将区间端点直接当精确失效日。

context 将摘要按强类型 schema 写入 Trialvault，并独立批准为本地研究发布。use_temperature_c 只表示业务拟评估的使用温度，不含寿命答案。


inspection_records 保留巡检原始行，result 为 normal 或 failed；kind=exact 是精确失效，左右端点相等。每个试件的 entry_day 独立保存，右删失由最后一次正常巡检结束。
